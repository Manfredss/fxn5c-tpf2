# FXN5C v0.37 — 车顶、散热窗与百叶动画更新

从首个公开版本 v0.24 到 v0.37，本次集中更新车顶轮廓、散热设备和涂装衔接，国铁与金温十个车号同步。

## 修改内容

- 按实车参考调整车顶分段斜率、设备布局、空调周边及检修盖形态；检修盖不再沿机车纵向形成错误坡度。
- 调整双格风扇、随车体轮廓的护网，以及风扇下方的侧墙散热窗；补充风扇和排气口腔体内壁，减少从开口直接看穿车体的情况，保留必要通风开口。
- 修正散热窗大小、位置及数量：两侧采用已修正的布局，包含三组双列大散热窗与端部较低矩形格栅。
- 修复国铁蓝带、金温涂装在散热窗和叶片上的衔接。
- 风扇可旋转；大散热窗百叶改为上下开合的结构，并在本版固定保持 55° 打开，不再循环闭合。
- 车顶侧面小百叶逐片、自上而下波浪开合，周期 0.8 秒，最大开度 40°。近景每窗由 10 片减至 9 片，叶片高度增加约 13%；中景相应简化。
- 保留“全部动画 / 仅风扇 / 静态”三种展示选项；三种选项下大散热窗均保持打开。更改选项后请重载。

## 下载与源文件

- `FXN5C_TPF2_v0.37.zip`：游戏模组；解压后使用完整 `codex_fxn5c_1` 文件夹。
- `FXN5C_SourceKit_v0.37.zip`：可编辑 Blender 场景、贴图、生成/检查脚本、原生资源，以及 v0.36 必要构建基线。
- 本版没有新导出的静态 FBX；仓库旧版 FBX 仅代表 v0.24，不代表本次模型。
- GitHub 自动生成的 Source code ZIP 不等于 SourceKit；完整历史基线请下载上述附件。
- 更新前备份存档，避免同时启用资源 ID 相同的本地版与工坊版。
