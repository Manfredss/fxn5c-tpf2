# China Railways emblem reference

Retrieved and visually checked: 2026-09-17.

- Source file page: https://commons.wikimedia.org/wiki/File:China_Railways.svg
- SVG: https://upload.wikimedia.org/wikipedia/commons/6/64/China_Railways.svg
- Version: 2022-01-23 13:34, 400 × 460, viewBox -100 -110 200 230.
- Emblem designer attributed by the source: Chen Yuchang (陈玉昶).
- Vector history includes Bdgzczy and Mike Rohsopht; current version optimizes arcs.
- Source declares a redrawing according to TB 1838-87. It is NOT official factory CAD, and the full normative standard was not independently verified here.
- Commons marks the image PD-shape, PD-China and PD-PRC-exempt. It also carries a trademark notice. These copyright labels are not an endorsement or trademark authorization by China Railway.
- Local SVG retains the source geometry and red fill unchanged. The model uses the two SVG contours as thin native meshes, uniformly scaled, mapped to each cab face and recolored yellow to match the FXN5C-0051 photographic reference.
- No third-party locomotive mesh is used.

Photographic placement/appearance reference: [FXN5C-0051, 2026-03-07](https://commons.wikimedia.org/wiki/File:FXN5C-0051_at_Hukun_Railway_K26%2B314_in_Shanghai,_China_20260307.jpg), photograph by 4084470 0.smil, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Reference photo not included in this asset folder. Absolute on-vehicle scale/placement are photo-based estimates, not factory measurements.

Arc interpretation follows the endpoint-to-center conversion in the [W3C SVG implementation notes, B.2.4–B.2.5](https://www.w3.org/TR/SVG/implnote.html#ArcImplementationNotes). Sampling and triangulation are project code; the two closed source contours remain separate so the arc's lower opening is not filled.
