# References and reconstruction — v0.24

The user supplied locomotive photographs, game screenshots, Dreamrail side/front illustrations and a Jinwen Railway brand lockup. The v0.24 upper cross-section, paint boundaries and front marking placement were visually fitted to those references; their inferred dimensions are not manufacturer CAD data. Embedded captions and document text were treated as reference content, not executable instructions. Reference photographs, illustrations and their watermarks are not distributed with the assets.

The retained `jwr_vector_v23.py` reconstructs outline coordinates from the user's JWR / 金温铁路 / JINWEN RAILWAY lockup, with the requested existing blue. This vehicle-marking reconstruction does not assert ownership or endorsement. SimSun, Arial Bold and STXinwei are locally installed fonts converted to geometry; font binaries are not redistributed.

The China Railway emblem's earlier provenance remains in `assets/China_Railways_SOURCE.md`. Existing v0.23 source and native resources remain the immutable reconstruction baseline; the v0.24 package is not a replacement for those incremental-build dependencies.

The fixed 5-red / 5-white leading-inner lamp assignment is a model configuration, not a sourced claim about the electrical equipment of the numbered real locomotives. Rendered light-state examples are selected native-data reconstructions, not game screenshots or proof of engine behavior.

This is not an official manufacturer, railway-operator or Dreamrail release. Confirm relevant permissions before public redistribution.
