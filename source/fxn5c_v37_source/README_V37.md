# FXN5C v0.37 大窗常开、小百叶调整

- 大散热窗固定在此前的 55° 打开姿态，不再循环闭合；“全部动画”“仅风扇”“静态”三种选项均保持大窗打开。
- 车顶侧面小百叶近景每窗 10 片减至 9 片，窗框外形与宽度不动；叶片高度由 29 mm 增至约 32.78 mm（约 +13%），保持安装间隙。中景从 5 片简化为 4 片。
- 小百叶最大开度从 32° 增到 40°，保持自上而下波浪顺序和 0.8 秒周期。风扇、涂装及其他设备保持。
- 国铁、金温全部十个车号同步。这些数值是展示模型配置，不宣称实车温控或精确机械尺寸。

## 验证范围

原生资源只替换小百叶与其轴端支座；车体网格采用支座局部三角形差分。大窗保留原网格与涂装，只改为固定旋转变换；不靠“暂停在某帧”保持打开。

减少叶片后，在原有节点位置留空组保留所有旧节点编号，避免影响灯光、走行部及元数据索引。未引用的旧叶片不会进入游戏候选 ZIP。

检查全部原生模型、文件引用、节点、远近级别、面数、矩阵和动画曲线；对源场景逐对象检查非目标网格/UV/材质/变换不变。对照源场景和最终原生叶片，按每 5 毫秒插值检查错峰叶片与边框、邻片的间隙；大窗检查固定打开姿态、背衬与框架。合页的设计接触不作干涉。三种动画选项都验证大窗固定姿态。

预览是最终原生资源离线回读，不是游戏截图。候选验证时未游戏或 Model Editor 实测；发布状态以工坊和 GitHub 页面为准。实际游戏仍建议两侧分别观察完整循环和远近切换，并切换三个动画选项后重载存档确认。

## 源文件与重建

权威入口为 build_v37.py 和 shutters_v37.py，以相邻 fxn5c_v36_source 的六个最终场景、原生模型和清单为基线。源码包包含这批基线。首次准备工作目录需复制基线 staging、source_textures；候选源码已备齐。

用 Blender 后台运行 build_v37.py、normalize_sourcekit_v37.py；Python 运行 verify_v37.py、audit_options_v37.py；Blender 运行 audit_geometry_v37.py、preview_native_v37.py --motion 与 --jinwen；目检后 Python 运行 package_v37.py。需要 NumPy、lupa、Pillow；不分发运行库二进制或字体，未宣称干净机器一键重建已验证。

可编辑近景场景是 fxn5c_source.blend、fxn5c_jinwen_source.blend，中远景是 runtime/final37_*.blend。大窗在源场景中也保持打开。小百叶循环由原生 .ani 定义，不是 Blender Action；手改最终场景不会自动进入生成器。清单 animated 是保留的部件接口字段，其中 fixed_degrees 标记的大窗节点没有循环动画。

保留旧版，使用完整 codex_fxn5c_1 目录，避免同时启用相同资源 ID 的本地与工坊副本。
